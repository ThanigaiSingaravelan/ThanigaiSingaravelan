## Featured project

### [LLAMAREC: Cross-Domain Recommender System using LLMs](https://github.com/ThanigaiSingaravelan/llamrec)

My MSc dissertation, marked at 85%.

LLAMAREC recommends books, films, TV and music by learning from what a user likes in one area and carrying it over to another. It runs Llama 3 models (8B and 70B) locally through Ollama, so no personal data leaves the user's machine.

- Combines retrieval-augmented generation with standard, few-shot and chain-of-thought prompting
- Compares each approach on cold-start users (almost no history) and warm-start users
- Includes a reproducible evaluation framework, with an explanation attached to every recommendation
- Uses a Python pipeline that turns large Amazon review datasets into multi-domain user histories

`Python` `PyTorch` `Llama 3` `Ollama` `RAG` `Hugging Face` `Pandas` `NumPy`
